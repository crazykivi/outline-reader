# Outline Reader

Десктопное приложение для чтения документации из Outline с локальным кэшированием и шифрованием хранилища.

Приложение синхронизирует коллекции, документы и вложения в локальную зашифрованную базу SQLite и предоставляет интерфейс для работы с ними без необходимости постоянного подключения к серверу.

## Возможности

- Локальная зашифрованная база данных (Adiantum VFS) с открытием по мастер-паролю
- Аргон2id (128 MiB, t=4) для деривации ключа из мастер-пароля
- Автоматическая блокировка базы при блокировке рабочей станции и уходе системы в сон
- Защита от захвата экрана через `WDA_EXCLUDEFROMCAPTURE` (исключение окна из скриншотов и записи)
- Прогрессивная задержка (lockout) при вводе неверного мастер-пароля
- Полнотекстовый поиск по документам (SQLite FTS5)
- Кэширование вложений и изображений для работы без подключения к сети
- Portable-режим: хранение всех данных в каталоге рядом с исполняемым файлом
- Очистка профиля WebView2 при запуске и завершении
- Блокировка повторных одновременных запусков с фокусировкой уже открытого окна
- Защита от автоматического заполнения мастер-пароля менеджерами паролей

## Стек

- Backend: Go
- Frontend: JavaScript / TypeScript / HTML / CSS
- Обвязка: Wails (системный WebView)
- СУБД: SQLite3 (WASM-сборка со встроенным FTS5)

## Portable-режим

Распакуйте архив и убедитесь, что рядом с `outline-reader.exe` находится пустая папка `data`. Приложение будет хранить в ней базу данных, профиль WebView2 (тему, размеры панелей, состояние раскрытых узлов дерева) и все служебные файлы. Каталог `%APPDATA%` в этом случае не используется.

Если папка `data` отсутствует или недоступна для записи, приложение переключается в обычный режим и использует `%APPDATA%\OutlineReader`.

Готовый portable-архив уже содержит пустую папку `data`.

## Сборка из исходников

Требуется Go, Wails CLI и Node.js.

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest

wails build -clean -trimpath -ldflags "-s -w"
```

Для разработки:

```bash
wails dev
```
