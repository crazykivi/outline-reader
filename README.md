# Outline Reader

Десктопное приложение для чтения документации из Outline с локальным кэшированием и шифрованием хранилища.

Приложение синхронизирует коллекции, документы и вложения в локальную зашифрованную базу SQLite и предоставляет интерфейс для работы с ними без необходимости постоянного подключения к серверу.

## Возможности

- Локальная зашифрованная база данных (Adiantum VFS) с открытием по мастер-паролю
- Аргон2id (128 MiB, t=4) для деривации ключа из мастер-пароля
- Автоматическая блокировка базы при блокировке рабочей станции, уходе системы в сон и при простое (5 минут)
- Защита от захвата экрана через `WDA_EXCLUDEFROMCAPTURE` (исключение окна из скриншотов и записи)
- Прогрессивная задержка (lockout) при вводе неверного мастер-пароля
- Полнотекстовый поиск по документам (SQLite FTS5)
- Кэширование вложений и изображений для работы без подключения к сети
- Инкрементальная синхронизация раз в минуту, полная — раз в сутки и по требованию
- Настройки интерфейса (тема, размеры панелей, раскрытые узлы дерева, масштаб) хранятся в зашифрованной базе
- Шифрование существующего кэша старого формата на месте, без повторной синхронизации
- Portable-режим: хранение всех данных в каталоге рядом с исполняемым файлом
- Работа в системном трее Windows: закрытие окна скрывает приложение, меню позволяет открыть его или полностью выйти
- Очистка профиля WebView2 при запуске и завершении
- Блокировка повторных одновременных запусков с фокусировкой уже открытого окна
- Защита от автоматического заполнения мастер-пароля менеджерами паролей

## Работа в системном трее Windows

Закрытие окна скрывает приложение, но не завершает его работу: Outline Reader продолжает работать в фоне, а иконка остаётся в области уведомлений рядом с часами. Чтобы вернуть окно, дважды щёлкните по иконке или выберите «Открыть» в её контекстном меню. Для полного завершения приложения выберите «Выйти».

## Стек

- Backend: Go
- Frontend: JavaScript / TypeScript / HTML / CSS
- Обвязка: Wails (системный WebView)
- СУБД: SQLite3 (WASM-сборка со встроенным FTS5)

## Portable-режим

Распакуйте архив и убедитесь, что рядом с `outline-reader.exe` находится пустая папка `data`. Приложение хранит в ней зашифрованную базу, настройки интерфейса (тему, размеры панелей, состояние раскрытых узлов дерева, масштаб) и все служебные файлы. Каталог `%APPDATA%` в этом случае не используется.

Профиль WebView2 в portable-режиме создаётся во временном каталоге системы и очищается при запуске и завершении, чтобы не оставлять следов на чужом компьютере. Настройки интерфейса от него не зависят: они лежат в зашифрованной базе и переезжают вместе с папкой `data`.

API-ключ Outline тоже хранится внутри зашифрованной базы, поэтому перенос каталога `data` на другой компьютер не требует повторного ввода ключа.

Если папка `data` отсутствует или недоступна для записи, приложение переключается в обычный режим и использует `%APPDATA%\OutlineReader`.

Готовый portable-архив уже содержит пустую папку `data`.

## Файлы данных

| файл | назначение |
| --- | --- |
| `cache.db` | зашифрованная база: документы, коллекции, вложения, настройки |
| `db.salt` | соль для деривации ключа из мастер-пароля |
| `unlock.guard` | счётчик неудачных попыток и время блокировки ввода |

Мастер-пароль не хранится и не восстанавливается. Сменить его можно только очистив локальную базу — документы будут синхронизированы с сервера заново.

## Замечания о шифровании

- Adiantum — детерминированное шифрование без MAC: база защищена от чтения, но не от подмены или отката файла на прежнюю версию. Резервные копии имеет смысл подписывать и проверять перед восстановлением.
- Прогрессивная задержка при неверном пароле — защита интерфейса: файл `unlock.guard` можно удалить. Реальную стойкость перебора обеспечивает Аргон2id.
- Вложения кэшируются в той же зашифрованной базе, отдельного незашифрованного кэша на диске нет.

## Сборка из исходников

Требуется Go и Wails CLI. Node.js не нужен: фронтенд собирается без бандлера.

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest

wails build -clean -trimpath -ldflags "-s -w"
```

Для разработки:

```bash
wails dev
```

Тесты:

```bash
go test ./... -race -count=1
```
