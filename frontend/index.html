О программе

Outline Reader

dev

Локальный ридер для Outline Wiki: дерево коллекций, полный текстовый поиск и зашифрованная копия базы на диске. Только чтение — данные в Outline не изменяются.

Исходный код Лицензия Apache-2.0
github.com/crazykivi/outline-reader

Опасная зона

Действия необратимы и затрагивают только локальные данные.

Очистить локальную базу Удалит копию документов, настройки подключения и мастер-пароль. Документы в Outline не пострадают.

Перейти

Выберите документ

Ctrl+K — поиск по базе, Ctrl+P — быстрый переход, Ctrl+F — поиск в документе.

Enter — открыть · ↑↓ — выбор · Esc — закрыть

Подключение

Ридер только читает данные и хранит копию локально. Ключ используется лишь для запросов к серверу Outline.

Очистить локальную базу?

Будут удалены локальная копия документов, настройки подключения и состояние синхронизации. Приложение вернётся к экрану первого запуска.

Документы в самом Outline не пострадают: ридер работает только на чтение и не умеет их изменять или удалять.
