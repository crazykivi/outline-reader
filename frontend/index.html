Выберите документ

Ctrl+K — поиск по базе, Ctrl+F — поиск в документе.

Подключение

Ридер только читает данные и хранит копию локально. Ключ используется лишь для запросов к серверу Outline.

Очистить локальную базу?

Будут удалены локальная копия документов, настройки подключения и состояние синхронизации. Приложение вернётся к экрану первого запуска.

Документы в самом Outline не пострадают: ридер работает только на чтение и не умеет их изменять или удалять.
